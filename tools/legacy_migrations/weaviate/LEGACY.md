# Legacy Weaviate Migration Utilities

These files are retained only for historical recovery, provenance, and audit of the completed Weaviate Cloud to Pinecone migration.

They are not part of the production runtime, are not imported by `backend/`, and are not copied into the Lambda image.

Old artifact IDs or paths in release metadata may still contain historical names. Do not rename them unless checksums, manifests, and MongoDB release metadata are updated and validated end to end.
